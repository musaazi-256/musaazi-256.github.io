AdWrap website static snapshot (captured 2026-10-18)

This is the compiled Next.js output from adwrapapp.com, not the original source.
Run it from this folder with a local server so the /_next/... paths resolve:

  npx serve .          (then open http://localhost:3000)
  or: python3 -m http.server 8000

Notes:
- Some images load from external hosts (i.ibb.co, storage.helloreaddy.io), so you need internet for those.
- Forms, /api/track analytics and client-side navigation that fetch live data will not work offline.
- Use "serve" with clean URLs (default) so /about maps to about.html.
